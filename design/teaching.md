# 困惑梳理与教学改造

## 问题根源

此前页面解释了局部计算，但没有充分连接“图像数值 → 局部加权测量 → 空间响应图 → 多通道 → 可选汇总 → 后续网络”。用户容易把尺寸、数值、信息量和重要性混在一起。改造重点是固定小例子、明确比较对象、给出反例，避免增加更多孤立术语。

| 用户困惑 | 需要区分的概念 | 实现的实验 |
|---|---|---|
| 卷积究竟在测量什么 | 原始像素、局部权重与特征响应 | 移动黑白边界、切换方向与均匀图，观察同一差分核的响应 |
| RGB 如何参与卷积 | 输入通道与输出通道 | 三个通道分别相乘求和，再相加并只加一次偏置；增加完整核产生新通道 |
| 为什么窗口里的多个数只产生一个输出 | 对应乘积与加权求和 | 固定 4×4 输入、2×2 核，点击每个输出追溯窗口，展示四个乘积和偏置 |
| 4×4 到 3×3 是不是压缩 | 空间尺寸、通道数量、激活数、参数量 | 可切换补零、步幅、核大小及通道；比较 9、16 和 90 个输出数 |
| 卷积完了以后做什么 | 特征变换与分类输出 | 同一输入依次完成两层卷积、激活、可选池化、全局平均和线性头 |
| 池化是不是必需，怎么选择 | 结构设计与可学习参数 | 最大、平均、不池化对照；可选步幅 1/2，显示各窗口来源 |
| 为什么最大值就是最重要的信息 | 局部数值极值与任务贡献 | 强响应移动但池化不变、异常尖峰被保留；明确池化不判断语义 |
| RGB 数字大的颜色会不会被当作重点 | 原始通道、学习后的特征通道 | 全白对差分核响应为 0，边界为 1；RGB 通道最大值组合出原图没有的白色 |

## 阅读流程

首页路线：卷积七步课 → 手绘验证 → 3D 结构。首页不再加载全连接课程。七步依次为：图像与响应、逐项乘加与扫描、尺寸、多通道、响应与重要性、可选池化、完整流程。新专题每次显示一个问题，保留明确的上一步、下一步及过渡解释。正文以 17–18px 为主，矩阵数字约 22px，手机纵向排列，避免缩成不可读的小字。

## 数学与结论边界

- 4×4 输入与 2×2 核扫描采用步幅 1、无补零、互相关。偏置为 0，但参数数量仍包含偏置。
- 小型 CNN 的所有前向值真实计算，权重手工设置，类别分数仅为未训练示例。未实现训练，不能宣称识别能力。
- 池化默认 2×2、步幅 2、不补零，不足窗口的边缘舍弃；平均池化和最大池化都可能丢失细节。
- RGB 例按通道取最大值，不假装它在选择某个最重要的原始像素。
- 数值数量不能直接衡量信息量；特征响应强不能直接等同于对任务重要。
- U-Net 衔接强调逐像素输出、空间细节及跳跃连接，不声称上采样能自动恢复丢失信息。

## 验证

新增纯计算测试覆盖尺寸、池化极值/平均值、位置丢失反例、差分对亮度和边界的不同响应，以及含/不含池化的完整前向路径。交互测试使用 DOM 替身验证路由和状态，不替代浏览器视觉验收。
